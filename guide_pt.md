## Introdução

A certificação **Claude Certified Architect — Foundations** atesta que um profissional sabe tomar decisões de trade-off ao implementar soluções reais baseadas em Claude. O exame avalia conhecimento fundamental sobre Claude Code, Claude Agent SDK, Claude API e Model Context Protocol (MCP) — as tecnologias centrais para construir aplicações em produção com Claude.

As questões do exame são baseadas em cenários realistas da indústria: sistemas agênticos para atendimento ao cliente, pipelines de pesquisa multi-agente, integração de Claude Code em CI/CD, ferramentas de produtividade para desenvolvedores e extração de dados estruturados a partir de documentos não estruturados.

---

## Candidato Alvo

O candidato ideal é um **arquiteto de soluções** que projeta e entrega aplicações em produção com Claude. Espera-se pelo menos 6 meses de experiência prática com:

- **Claude Agent SDK** — orquestração multi-agente, delegação para subagentes, integração de ferramentas, hooks de ciclo de vida
- **Claude Code** — CLAUDE.md, servidores MCP, Agent Skills, modo de planejamento
- **Claude API** — chamadas de ferramentas, saída estruturada, streaming, prompt caching
- **Model Context Protocol (MCP)** — desenho de servidores e clientes, transports, tools/resources/prompts
